## 🏛️ Executive Summary

**CLASSICAL VIEWER** is a regal, full-stack multi-agent AI inspection and debugging platform powered by the **SSbow Sovereign Engine**. Wrapped in a high-classical charcoal and metallic gold interface with continuous live motion canvas backgrounds, it provides real-time 3D/2D spatial agent topology charts, synchronized ReAct CLI log streaming, delegation gap tracking, an autonomous **Meta-Debugger**, and a dedicated **Swarm Agents Troubling Column**.

## ⚡ Core Capabilities

### ⚔️ Dual Swords Regal Branding & Moving Live Motion Background
- **Emblematic Dual Swords (`Swords`)**: Custom animated emblem with gold glint and pulse aura effects.
- **Continuous Motion Wave Canvas**: Dynamic moving linear background grids (`bg-live-motion-grid`) and animated ambient gradient waves (`bg-live-motion-wave`) for a live, living workspace.

### 🔥 Swarm Agents Troubling Column
- Dedicated homepage column isolating active swarm faults in real time.
- Categorizes issues into **Delegation Deadlocks**, **Loop Hallucinations**, **Schema Drifts**, and **Latency Spikes**.
- Quick action controls to **Isolate Agent**, **Auto-Patch System Prompts**, or **Trace CLI Stream**.

### 🧠 SSbow Sovereign Meta-Debugger
- Autonomous AI auditor that inspects multi-agent trace trees for failure stacks and hallucinations.
- Generates precise system prompt patches and applies them directly to targeted agent nodes.

### 🎮 Classical Keyboard Shortcuts
- **`[Space]`** — Toggle Play / Pause simulation playback.
- **`[R]`** — Instant reset to Step #1.
- **`[D]`** — Toggle the SSbow Meta-Debugger drawer.
- **Hover Help Badge** in footer for quick shortcut references.

## 🛠️ Architecture & Tech Stack

- **Framework**: React 18, Vite, TypeScript
- **Styling**: Tailwind CSS, Lucide React Icons, Cinzel & Serif Typography
- **Animation & Motion**: Motion (`motion/react`), Custom CSS Keyframe Motion Grids
- **Data Visualization**: Recharts, D3 3D Spatial Canvas
- **Server Environment**: Express + Vite Integration (`server.ts`)

## 🚀 Quick Start Guide

### Prerequisites
- Node.js 18+
- npm / pnpm

### Installation & Execution

```bash
# Clone the repository
git clone https://github.com/your-org/classical-viewer.git
cd classical-viewer

# Install dependencies
npm install

# Launch Development Server
npm run dev
```

Open `http://localhost:3000` in your browser to experience **CLASSICAL VIEWER**.
